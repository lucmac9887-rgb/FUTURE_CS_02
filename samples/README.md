# Email Samples

This directory contains educational email samples used for the Future Interns Task 2 phishing email analysis.

For each sample, the analysis will document:
- Sample source
- Email subject and sender details, when available
- Suspicious indicators
- URL observations, where applicable
- Risk classification and supporting evidence

Only samples used for defensive security education will be included. Suspicious links will not be opened, and attachments will not be executed.

Analysis results will be documented after each sample has been reviewed.
